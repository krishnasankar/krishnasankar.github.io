What is Poi Spinning?

Poi is a traditional flow art originating from the indigenous Māori people of New Zealand. It involves swinging tethered weights rhythmically in geometric patterns and circular planes around the body. It blends rhythm, motor coordination, spatial geometry, and movement meditation.

MonthlyExpenseTracker

A modern, offline-first native Android application built with Jetpack Room (SQLite) to track and budget personal expenses on a monthly basis with zero cloud dependencies.

  • Month-by-month navigation, search & customizable hierarchical categories with cascade safety
  • Budgeting v2.0: Monthly spending target, live pacing alerts & dynamic Safe Daily Spend calculator
  • Interactive Canvas-rendered Donut Chart with touch selection, metric cards & category breakdowns
  • Home Screen App Widget for instant monthly status and 1-tap quick expense entry

🤖 Android · AI Assistant
⭐ Flagship Project
Android OpenRouter AI Java Tool Calling Voice Input Jetpack Security Markwon

NotePilot

A private, intelligent personal assistant Android application that reasons over personal notes and checklists, answering queries and autonomously updating records via LLM tool calling.

  • Dynamic context retrieval: Injects notes & checklists directly into OpenRouter LLM context
  • Function calling (addOrUpdateNote): Autonomous creation & updates for tasks, reminders & birthdays
  • ContentChangeGuard: Safety confirmation modal previewing change diffs before committing AI edits
  • Voice input with Android Speech Recognition, encrypted BYOK API storage & Markwon chat UI
