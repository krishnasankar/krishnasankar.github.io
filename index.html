⭐ Flagship Project
Android OpenRouter AI Java Tool Calling Voice Input Jetpack Security Markwon

NotePilot

A private, intelligent personal assistant Android application that reasons over personal notes and checklists, answering queries and autonomously updating records via LLM tool calling.

  • Dynamic context retrieval: Injects notes & checklists directly into OpenRouter LLM context
  • Function calling (addOrUpdateNote): Autonomous creation & updates for tasks, reminders & birthdays
  • ContentChangeGuard: Safety confirmation modal previewing change diffs before committing AI edits
  • Voice input with Android Speech Recognition, encrypted BYOK API storage & Markwon chat UI
